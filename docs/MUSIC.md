## 실제 기능
- 마을 ☰ → 작은 연주. 숲의 기존 마을 캐릭터가 칼림바를 쥔다. 최초 터치로 오디오 잠금 해제(이미 열린 소리는 누르는 즉시, 잠긴 첫 손가락 입력은 활성화가 보장되는 손을 떼는 이벤트에서 시작). 오음계 8음(도·레·미·솔·라·높은 도·레·미), 눌렀을 때 소리, 건반, 손/금속 건반의 짧은 움직임, 음표의 반응. WebGL 실패 시에도 연주판은 사용 가능.
- 자유 연주는 언제든 가능. 녹음 버튼으로 최대 30초/64음(첫 음 앞 침묵 제외, 실제 시간 간격 보존). 녹음 끝 → 다시 재생(제목 미정이어도 가능), 제목 입력, 저장/공유/그만두기. 저장·공유에만 제목 검사를 적용한다. 제목 입력 칸은 UTF-16 32단위로 제한하고 규칙은 32 유니코드 문자까지 검증한다. 24곡까지 보관, 이름 변경·재생·삭제. 한도는 구현의 초깃값이지 성장 규칙이 아니다.
- 오디오 시계를 사용해 재생, 120ms 앞만 예약. 탭 숨김/페이지 이동/정지 때 소리 취소, 자동 재생 없음. 칼림바 합성음(샘플·원곡 음원 없음), 기기별 음색/음량/지연은 사용자가 직접 확인해야 한다.
- 친구에게 보낼 주소는 음과 시간, 제목만 UTF-8 base64url로 담는다. 엄격한 길이·판·음·시간·제목 검증, 자동 저장/재생 없음. 주소를 아는 사람이 듣는 것이며 온라인 합주나 서버 방송은 이번 범위 밖.
- 음악 보관은 별도 maeul:music v1, validate→apply→inverseOf, 원본을 유지하고 오류/새 버전/저장 전에 읽은 원문과 현재 원문을 비교해 다른 탭의 변경을 감지하면 쓰기 금지. 로컬 저장소의 원문 비교는 여러 탭의 완전히 동시인 쓰기까지 원자적으로 보장하지는 않는다. 집·낚시·채집·온라인 저장 규칙 미변경. 저장소를 지우면 곡을 잃을 수 있다. 다른 기기에서는 공유 주소로 감상 가능. 저장 충돌로 차단될 때에는 새로고침 전 아직 화면에 남은 곡의 공유 주소를 복사해 보관하도록 안내한다(보관함에 자동 복구되는 기능은 아니다).
- 실기기 종료 조건: 직접 자유 연주, 녹음·재생·저장 후 재접속, 링크를 받은 친구가 들어 보기. 자발적 연주와 재생 관찰. 동시 합주, 레벨, 스킬 성장, 악기 제작/해금은 미구현.
